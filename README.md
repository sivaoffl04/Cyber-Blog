# Cyber-Blog

Welcome to **Cyber-Blog**! 👋

This repository is my personal cybersecurity blog and hands-on knowledge base. Here, I document and publish everything I learn in cybersecurity on a regular basis—covering practical research, hands-on labs, real-world attack techniques, and defensive security engineering.

---

## 🎯 What I Cover

As I learn and explore new areas of security, I upload comprehensive write-ups and notes across:

* 🔴 **Red Team (Offensive Security):** Mobile application penetration testing (Android), reverse engineering, exploit analysis, and offensive tradecraft.
* 🔵 **Blue Team (Defensive Security):** Security Operations Center (SOC) workflows, EDR telemetry, SIEM event correlation, automated SOAR playbooks, and YARA rule hunting.
* 🟣 **Purple Teaming:** Adversary emulation, telemetry verification, and collaborating to turn offensive techniques into strong detection capabilities.
